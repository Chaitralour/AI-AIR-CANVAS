# 🎨 AirCanvas Pro

A gesture-controlled drawing application built using **Python**, **OpenCV**, and **MediaPipe**.

## Features

- ✋ Real-time hand tracking
- 🎨 Draw using index finger
- ✌️ Selection mode using two fingers
- 🌈 Multiple brush colors
- 🧽 Eraser
- 🗑 Clear canvas
- 💾 Save drawing
- 📈 FPS counter
- 👋 Two-hand detection

## Tech Stack

- Python
- OpenCV
- MediaPipe
- NumPy

## Installation

```bash
pip install -r requirements.txt
python main.py
```

## Controls

| Gesture | Action |
|---------|--------|
| ☝️ Index Finger | Draw |
| ✌️ Index + Middle | Selection Mode |
| S | Save Drawing |
| Q | Quit |
